# Worker-experience revision

- Bare `report hours` / `report hour` opens a deterministic instruction reply;
  an actual correction note creates the existing manager-review record. An empty
  request creates neither a work update nor an empty time exception.
- Optional work coaching cannot confirm timekeeping writes. The bounded response
  guard drops detected time-state/write claims and retains the deterministic work
  receipt. This guard is deliberately conservative, not a proof about every possible
  natural-language output. The AI has no attendance mutation tool.
- Standalone acknowledgements stay quiet, with no AI call or attendance activity.
- Clear present-tense call/dealership updates can create a new pending workstream
  record. PERDEX and BrightDrop labels do not authorize contract charging. Earlier
  records remain unchanged; ambiguous, historical and hypothetical notes are not
  automatically reclassified by these patterns.
- Returning after an already-ended break reports whether the work clock is running
  or stopped, and gives the appropriate restart path. Clock-out still ends lunch
  without restarting a stopped shift. Existing onsite, minimum-return, remote and
  overtime checks remain in force. No historical punches are replayed.
- `work channel review` is owner-only triage of the latest 100 useful captured
  posts (up to ten candidates). It links possible blockers, direction changes and
  unmapped work back to sources; these hints are not an accepted plan or a confirmed
  contradiction. `work channel updates` retains the existing actor/owner boundary.
- Ordinary channel capture remains default-off until Slack scopes/subscriptions
  are approved and installed. No backfill, automatic cross-channel digest, new
  audience, staff announcement, image interpretation or payroll write is included.

Acceptance: try `report hours`, an actual workstream switch, and a casual `thanks`
in the existing DP DM. Verify the actual correction in manager review before
changing any hours. Only after channel activation, check a real ordinary worker
post and its source link; do not manufacture production time for a test.
